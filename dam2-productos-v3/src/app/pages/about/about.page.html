Sobre Mi Tienda DAM2

Mi Tienda DAM2 es una tienda online de ejemplo creada como práctica del módulo de Desarrollo de Interfaces de 2º de DAM. Nuestro catálogo reúne productos de categorías muy distintas, desde calzado y relojes hasta artículos para el hogar, y se muestra siempre al día porque se alimenta en tiempo real de una API REST pública.

La aplicación está desarrollada con Ionic y Angular Standalone. Ofrece una consulta clara del catálogo: precio, descuento, valoración, dimensiones, stock y el valor total del stock de cada producto, todo ello paginado para navegar con comodidad.
